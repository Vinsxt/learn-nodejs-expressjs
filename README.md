# Node.js & Express.js Backend Development

A hands-on backend development learning project focused on understanding how server-side applications work, building REST APIs, implementing authentication, and integrating databases.

This project follows the [Node.js & Express.js Tutorial](https://www.youtube.com/watch?v=9BD9eK9VqXA), with additional experimentation and implementation along the way.

## Learning Objectives

- Understand Node.js fundamentals and server-side JavaScript.
- Build backend applications using Express.js.
- Design and implement RESTful APIs.
- Handle HTTP requests, responses, routing, and middleware.
- Implement user authentication and authorization.
- Work with relational databases and SQL queries.
- Understand ORM concepts and database migrations using Prisma.
- Containerize applications and manage development environments using Docker.

## Technologies & Tools

- **Runtime:** Node.js
- **Backend Framework:** Express.js
- **Database:** SQLite, PostgreSQL
- **ORM:** Prisma
- **Authentication:** JSON Web Tokens (JWT), bcrypt
- **Containerization:** Docker, Docker Compose
- **Development Tools:** Git, npm, Postman

## Project Structure

The repository is organized into chapters, with each chapter introducing additional backend concepts and implementation challenges.

| Chapter | Focus |
|---|---|
| Chapter 2 | Node.js and Express.js fundamentals, server setup, and REST API development |
| Chapter 3 | Database integration, CRUD operations, user authentication, and authorization |
| Chapter 4 | PostgreSQL integration, Prisma ORM, database migrations, and Docker containerization |

## Key Concepts & Implementations

### 1. Node.js & Express.js
- Understanding the Node.js runtime and asynchronous JavaScript.
- Creating HTTP servers and handling incoming requests.
- Setting up Express applications.
- Defining routes and organizing endpoints using Express Router.
- Handling request parameters, query strings, and JSON request bodies.
- Implementing middleware for request processing and error handling.

### 2. REST API Development
- Designing RESTful endpoints using HTTP methods (GET, POST, PUT, DELETE).
- Implementing CRUD (Create, Read, Update, Delete) functionality.
- Separating application logic into routes and reusable modules.
- Handling HTTP status codes and JSON responses.
- Testing API endpoints and understanding request-response workflows.

### 3. Database Integration
- Understanding relational database concepts and SQL.
- Connecting backend applications to databases.
- Performing database operations using SQL queries.
- Implementing CRUD operations with database persistence.
- Understanding relationships between users and their associated data.

### 4. Authentication & Authorization
- Implementing user registration and login.
- Hashing passwords securely using bcrypt.
- Generating and verifying JSON Web Tokens (JWT).
- Understanding authentication middleware.
- Protecting routes and restricting access to authenticated users.

### 5. Prisma ORM & PostgreSQL
- Understanding the role of an Object-Relational Mapper (ORM).
- Defining database models using Prisma Schema.
- Connecting an Express application to PostgreSQL through Prisma Client.
- Performing database queries using Prisma.
- Managing database schema changes through migrations.

### 6. Docker & Containerization
- Understanding containers and their role in application development.
- Creating Dockerfiles to define application environments.
- Using Docker Compose to manage multiple services.
- Running an Express application alongside a PostgreSQL database.
- Understanding container networking, environment variables, and service configuration.

## What I Learned

Through this project, I developed a better understanding of how backend applications operate beyond simply writing API endpoints.

I learned how different components of a backend system work together, from receiving HTTP requests and executing application logic to interacting with databases, managing user authentication, and deploying services in containerized environments.

More importantly, this project helped me understand the underlying concepts and workflows involved in building a full-stack application, providing a foundation for more advanced backend development.
